# QA: M0 app shell and System Health (2026-10-14)

**Method** (after the trading app's `docs/qa/ui-exploratory-audit-2026-09-09.md`):
Chrome DevTools MCP on `./rag web` (dev mode), an isolated browser context.

- Every page × 375 / 768 / 1024 / 1280 / 1440 px: a script loads each in a sized
  iframe and measures page overflow, `<h1>` count, unnamed buttons and images
  without `alt`.
- Screenshots in dark (default) and light, desktop and phone (375 × 812 @2x).
- Keyboard: the skip link, ⌘K / Ctrl+K, Escape, the mobile sidebar focus.
- Console: errors and warnings across navigations.

**Pages:** Ask, Documents, How it works, Evaluation, Indexes, Settings, System Health.

## Result

| Check | Result |
|---|---|
| Horizontal page overflow, 7 pages × 5 widths | none (35/35) |
| Exactly one `<h1>` per page | 35/35 |
| Buttons without an accessible name | 0 |
| Console errors / warnings | 0 / 0 (only React DevTools info and HMR logs) |
| Skip link | first Tab stop, moves focus to `#main` |
| ⌘K palette | opens with focus in the input, lists all 7 pages + theme, Escape closes |
| Mobile sidebar | opens as a sheet with focus inside; closes on navigation (after M0-05) |
| Light and dark | both render correctly; dark is the default |

## Findings

All were found and fixed in this pass. Severity: P0 broken · P1 wrong or
misleading · P2 degraded · P3 polish.

| ID | Sev | Finding | Fix |
|---|---|---|---|
| M0-01 | P2 | The Next dev indicator ("N") sat on the sidebar's status rows at bottom-left | `devIndicators.position: "bottom-right"` in `next.config.ts` |
| M0-02 | P3 | The top-bar divider was pinned to the top of the header (y 0-16 of 56) | The component's `data-vertical:self-stretch` beat a bare `self-center` (attribute selector; tailwind-merge keeps both because the variants differ). Call site now uses `data-vertical:h-4 data-vertical:self-center`; measured centre 27.5 vs header 28. The trading app uses the same component and call site, so it likely has the same defect (its F-020 fix); not measured there, and not changed, since that repo is read-only here |
| M0-03 | P2 | Models per role at 375 px: purposes squeezed into a one-word column, status pushed off-screen | Rebuilt as a list that stacks on phones and aligns as columns from `sm` |
| M0-04 | P2 | Installed models table scrolled sideways at 375 (488/343 px) and 768 (525/464 px, sidebar open) | Columns now respond to the card width via container queries (`@sm`, `@xl`, `@2xl`), with the hidden columns' content folded into the model cell. Fits at all five widths |
| M0-05 | P1 | On a phone, choosing a page left the sidebar sheet open over the page | Nav links call `setOpenMobile(false)` on click |
| M0-06 | P3 | "3 PDF(s)", "1 model(s)" | Real plurals |
| M0-07 | P3 | The Health summary card had a double outline (ring + border) when healthy | Border only when not healthy |
| M0-08 | P3 | "Running" used a spinner icon that did not spin, reading as stalled | Pulse icon (`Activity`) |
| M0-09 | P2 | `pnpm lint` failed on shadcn's `use-mobile` (setState in an effect) | Rewritten with `useSyncExternalStore` |
