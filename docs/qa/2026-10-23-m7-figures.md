## Findings

| ID | Severity | Finding | Status |
|---|---|---|---|
| M7-01 | P1 | `after.bad` is an object (`{raw, error}`) but the widget rendered it as text: any figure with a rejected output would have crashed the page ("Objects are not valid as a React child") | **Fixed** before the first render (type + `after.bad.error`) |
| M7-02 | P2 | The status tiles used viewport breakpoints inside a card (CLAUDE.md: container queries) | **Fixed** (`@container`, `@sm:` / `@3xl:`) |
| M7-03 | P2 | At a 768 px window the truth table needed 556 px in a 454 px card: units in every header, no wrapping; the Value column squeezed to 110 px | **Fixed**: units once in the summary line, short headers, "Within tolerance" wraps; Error hidden below `@sm` |
| M7-04 | P3 | A section path can end in a heading's footnote mark ("…recycled content. 1"): Docling's heading text, shown as is | Open (structure, not M7) |
